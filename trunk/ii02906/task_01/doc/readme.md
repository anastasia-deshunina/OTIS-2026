\# Лабораторная работа №1

\## Вариант 16



\### Модели

1\. \*\*Линейная модель 1.6:\*\* y\_{t+1} = a1\*y\_t + a2\*y\_{t-1} + a3\*y\_{t-2} + b\*u\_t

2\. \*\*Нелинейная модель 2.10:\*\* y\_{t+1} = a\*tanh(y\_t) + b\*u^3

3\. \*\*Дифференциальное уравнение 3.4:\*\* dy/dt = -a\*y^2 (метод Эйлера)



\### Архитектура (UML)

\- Абстрактный класс `Model` с виртуальным методом `step()`.

\- Классы-наследники: `LinearModel`, `NonLinearModel`, `DiffEqModel`.

\- UML-диаграмма: `uml.png`



\### Входные воздействия

\- Ступенчатое (u = const)

\- Импульсное (u = 1 при tau=0, далее 0)

\- Гармоническое (u = sin(tau))



\### Сборка

\- CMake + Visual Studio 2022

\- Запуск через `.exe` или `run\_tests.bat`



\### Результаты

\- Данные выводятся в консоль.

\- Результаты сохраняются в `results.csv`.

\- График: `graph.xlsx` / `graph.png`



\### Вывод

Программа реализует три модели, проводит симуляцию на N шагов,

сохраняет результаты в CSV и строит график.
